# Standard Coherence Fidelity Layer (SCFL)

Website for SCFL, an independent research program originated by Ronald L. Brogdon.

> SCFL measures the geometry of relational coherence in a system's state space.

Foundational paper: *Coherence as a Relational Property: Toward a Foundational Science of Coherence*, Ronald L. Brogdon and Juanita Rubio. https://doi.org/10.5281/zenodo.23247214

## Site

A static multi-page site served by GitHub Pages from the `main` branch, root folder. No build step or dependencies.

- Pages: `index.html`, `measurement-problem.html`, `approach.html`, `applications.html`, `case-texas-grid.html`, `case-fukushima.html`, `measurement-as-a-service.html`, `research.html`, `papers.html`, `videos.html`, `collaborate.html`, `one-question.html`, `register.html`, `404.html`
- Shared styles and scripts: `assets/`
- Custom domain: `CNAME`

**How to edit, add pages, update publications and maintain the site:** see [`_docs/HANDOVER.md`](_docs/HANDOVER.md).
